# Security Policy

## Supported versions

Security fixes are currently applied to the latest `0.1.x` release line and the default branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature on the repository's **Security** tab. If that
feature is unavailable, contact the maintainer through the GitHub profile without publishing exploit
details. Do not open a public issue for an undisclosed vulnerability.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should
receive an acknowledgement within seven days. No bounty or fixed disclosure timeline is currently
offered.

Documents processed by this library may contain sensitive data. Hosted OCR or vision integrations
must never upload document content without explicit user opt-in.
